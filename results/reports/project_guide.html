🎯 주가 예측 성능 비교 프로젝트

4가지 모델 기반 주가 예측 시스템

📋 프로젝트 개요

본 프로젝트는 주가 예측에서 과거 가격 데이터, 기술적 지표, 투자 심리 지수를 다양하게 조합하여 4가지 서로 다른 모델을 구축하고, 이들의 예측 성능을 비교합니다. 전통적인 시계열 모델부터 최신 머신러닝 기법까지 활용하여 어떤 방식의 조합이 가장 정확한 주가 예측을 가능하게 하는지 검증합니다.

🤖 4가지 예측 모델

1️⃣ 고전적 모델

설명: 시계열 데이터 기반 통계 모델

알고리즘: ARIMA

구현: src/classical_model.py

2️⃣ AI 기반 모델

설명: 가격 데이터와 기술적 지표 기반

알고리즘: Random Forest, ANN

구현: src/ai_model.py

3️⃣ 심리 지수 모델

설명: 투자 심리 지수만 사용

구현: src/sentiment_only_model.py

4️⃣ 하이브리드 모델

설명: 가격 + 기술적 지표 + 심리 지수 결합

알고리즘: Gradient Boosting

구현: src/hybrid_model.py

원본 데이터에서부터 모델 학습까지의 전체 처리 과정을 단계별로 설명합니다.

⚙️ 모델별 상세 정보

1. ARIMA (고전적 모델)

목적: 시계열의 자기상관성과 추세를 활용한 기본 예측

특징: 통계적 근거가 강하며 해석 가능성 높음

구현 파일: src/classical_model.py src/modeling.py src/train.py (train_classical_pipeline)

파이프라인: 데이터 로드 → 시계열 분할 → 자동 파라미터 탐색 → 모델 학습 → 잔차 진단 → 테스트 예측

2. Random Forest (AI 기반 모델)

목적: 기술적 지표를 입력으로 비선형 관계 학습

특징: 앙상블 방식으로 높은 일반화 성능

파라미터: n_estimators=200, random_state=42

구현 파일: src/ai_model.py

3. ANN (AI 기반 모델)

목적: 신경망을 통한 복잡한 패턴 학습

아키텍처: Input → 64 units (ReLU, Dropout 0.2) → 32 units (ReLU, Dropout 0.2) → 1 unit (Linear)

학습 전략: Early Stopping (patience=15), 외부 검증 데이터 활용

구현 파일: src/ai_model.py

4. Gradient Boosting (하이브리드 모델)

목적: 가격 정보와 심리 지수를 모두 활용한 최고 성능 모델

특징: 그래디언트 부스팅 방식으로 각 약한 학습기를 순차적으로 개선

구현 파일: src/hybrid_model.py

📈 모델 평가 지표

각 모델의 예측 성능을 평가하기 위해 다양한 지표를 사용합니다.

  • RMSE (Root Mean Square Error) - 예측 오차의 제곱 평균 제곱근
  • MAE (Mean Absolute Error) - 예측 오차의 절댓값 평균
  • MAPE (Mean Absolute Percentage Error) - 백분율 기반 오차
  • MBE (Mean Bias Error) - 편향성 평가
  • R² Score - 모델의 설명력
  • Directional Accuracy - 주가 상승/하락 방향성 맞춤 정확도

구현 파일: src/evaluate.py
